ZeroGate: Project Scope
ZeroGate is a Zero Trust access platform, built on NIST SP 800-207, that checks every
login, web request and SSH connection against the user's identity, device health and a live
risk score. Users sign in with a custom biometric passkey, reach servers only through SSH
certificates that expire in minutes, and lose access the moment risk rises. Every decision
is explainable, recorded in a tamper-evident log and measured for its performance cost.
In scope
Core features are required for the defense, add-ons strengthen the thesis, and stretch
goals happen only if time allows.

The latency dashboard and the hash-chained audit log are core rather than add-ons
because they are part of what makes the project novel.
Out of scope
We deliberately do not build these, so no requirement or diagram should include them.
The enterprise security suite: secure web gateway (SWG), CASB, data loss prevention
(DLP), remote browser isolation and firewall-as-a-service. These need a global proxy
network and threat intelligence.
Access to Kubernetes clusters and databases. Only web apps and SSH servers are
protected.
Email security and AI-agent governance.
Production deployment, real company data or real users beyond test participants.
FIDO certification of the custom passkey.
Hosting ZeroGate as a multi-tenant service for many organizations.
